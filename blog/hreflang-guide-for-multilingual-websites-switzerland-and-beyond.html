Hreflang guide
for multilingual
websites.

Multilingual sites often show the wrong language in search results. Hreflang and a clean structure fix most of it, especially in countries like Switzerland.

By Santiago Payá de la Cruz•October 17, 2026•8 min read

Why hreflang matters

Hreflang tells search engines which version of a page suits which language or region. Without it, a user in Geneva may see your German page, and your own versions may compete.

It is a signal, not a command, but it is essential when you publish several versions.

URL structure for Switzerland

Most Swiss sites use a folder per language, for example /de/, /fr/, /it/ and /en/. Each version has its own URL and its own content. Avoid auto-redirecting by IP or browser language, which search engines may not follow.

Choose one structure and keep it consistent.

How to write the tags

Each page lists every language version, including itself, with the language code (and region if needed), such as de-CH, fr-CH and it-CH. Add an x-default for a fallback page.

Tags must be reciprocal: if A points to B, B must point back to A.

Where to implement

You can place hreflang in the HTML head, in HTTP headers or in the XML sitemap. For large sites the sitemap is easier to maintain. Pick one method and verify it.

Check with Search Console and crawl tools.

Content, not just translation

Swiss German, French and Italian differ from other regions in vocabulary and formality. Local currency, legal references and examples matter. Use native writers who know the market.

Machine translation without review often misses the search terms real users use.

Common errors

Frequent problems include non-reciprocal tags, wrong language codes, tags pointing to redirected or blocked URLs, and mixed-language pages.

Audit regularly after site changes.

Where it usually goes wrong

The most frequent errors:

  • Redirecting by IP.
  • Missing return tags.
  • Wrong codes.
  • Untranslated sections.
  • Letting versions drift apart.

The mistake I see most

Hreflang tags that do not point back to each other, or point to pages that redirect. Google ignores them when they are inconsistent, and you get the wrong version in the wrong country.

Do fewer languages well. A machine-translated version nobody checks does more harm than no version at all.
